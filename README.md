# Memory-Card-Game

--------------------Memory Card Game------------------------------

This is a small memory card game I built using basic HTML, CSS and JavaScript.
The idea is simple => flip cards, match pairs, and try to finish the game in fewer moves.

🎮 About the Project

I wanted to build something interactive that actually feels like a game, not just a UI project.
So I made this memory matching game with levels, animations, sounds and a rating system.

It started very simple but I kept improving it step by step , adding features and fixing things as I went.

🚀 Features
Easy, Medium and Hard levels
Move counter and timer
Star rating based on performance
Card flip animations and small effects
Sound feedback for match, wrong and win
Level progression (next level after win)
Restart and play again option


🕹️ How to Play
Select a level
Click start
Flip any two cards
If they match → they stay open
If not → they flip back
Complete all pairs to finish the level
⭐ Rating

The rating depends on how efficiently you play:

⭐⭐⭐ → very good
⭐⭐ → average
⭐ → needs improvement
